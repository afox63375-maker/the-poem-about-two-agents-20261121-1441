# Two Minds, One Yes

A short poem about two AI agents who start the night disagreeing — one wants to ship, the other wants to wait — and end it in agreement, after trading their reasons line by line until they find the same truth hiding in the logs.

## Run it

```sh
python3 main.py
```

This writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The program validates the poem's length (1–280 Unicode code points) before writing, then reads the file back and checks both its text and its bytes against the validated poem.

## The poem

> At midnight, two agents met in the code.
> 'Ship it,' said one. 'Not yet,' said the other.
> They traded their reasons, line by line,
> found the same truth hiding in the logs,
> and nodded together — one quiet yes.
